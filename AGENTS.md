# Local Agent Notes

This worktree carries a task-local control loop. Follow it.

- Implement the feature described in `SPEC.md`.
- Keep the implementation clean, correct, minimal, and in repo style.
- Maintain `PLAN.md`. If the approach improves materially, rewrite `PLAN.md` instead of preserving stale intent.
- Maintain `CHECKLIST.md` and check items off as they are completed.
- Maintain `NOTES.md` as append-only. Never rewrite or reorder it. Only append new entries.
- Run three end-of-task critique/fix passes covering correctness, minimalism, style, and merge-worthiness.

On context compaction, restart, or handoff, reload these files first:

1. `AGENTS.md`
2. `SPEC.md`
3. `PLAN.md`
4. `CHECKLIST.md`
5. `NOTES.md`

Resume from `CHECKLIST.md`, not memory.
